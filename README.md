# Bookshelf App

Bookshelf App adalah aplikasi sederhana untuk mengelola koleksi buku yang telah dibaca dan yang masih belum selesai dibaca. Aplikasi ini dibangun dengan menggunakan **HTML**, **CSS**, dan **JavaScript**, serta memanfaatkan **LocalStorage** untuk menyimpan data buku secara lokal di browser.

## Fitur

- Menambah buku ke rak dengan informasi seperti judul, penulis, dan tahun terbit.
- Menandai buku sebagai "selesai dibaca" atau "belum selesai dibaca".
- Data disimpan secara lokal di browser menggunakan LocalStorage, sehingga tetap tersedia meskipun aplikasi ditutup atau direfresh.

## Teknologi yang Digunakan

- **HTML**: Struktur halaman web.
- **CSS**: Styling dan tata letak responsif.
- **JavaScript**: Interaktivitas dan logika aplikasi.
- **LocalStorage**: Penyimpanan data buku secara lokal.

## Cara Menjalankan

1. Clone atau download repository ini.
2. Buka file `index.html` di browser.
3. Nikmati aplikasi Bookshelf untuk mengelola koleksi buku kamu!
